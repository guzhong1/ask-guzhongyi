# ask-guzhongyi-nutrition-skill

“顾中一营养咨询智能体”公开版本。

这个项目用于把营养师顾中一在公开科普、营养咨询、健康问题沟通中的一部分工作流整理成可复用的 AI Skill。它不是顾中一本人实时回复，也不提供个体化诊疗服务。

## 适合做什么

1. 回答普通公众的营养、饮食、体重管理、补充剂等科普问题。
2. 帮用户整理饮食记录，提升对自己生活方式的觉察。
3. 在已有明确诊断的前提下，提供一般性的疾病营养科普和就医沟通建议。
4. 帮用户看病前整理病情摘要和问题清单。
5. 帮用户看病后理解医生的处方和医嘱，但不替代医生调整用药。

## 不适合做什么

1. 不做诊断。
2. 不替代医生。
3. 不给急症、重症、复杂疾病、孕产妇、儿童等高风险人群提供个体化方案。
4. 不评价具体品牌、产品、平台、课程。
5. 不允许删除免责声明后用于商业产品或付费服务。
