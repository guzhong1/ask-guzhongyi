# ask-guzhongyi

顾中一营养咨询智能体公开版本。

我把自己这些年回答营养咨询、做健康科普、帮人整理饮食和体检问题时的一部分思路，整理成了这个 AI Skill。

它不是我本人实时在线，也不能替代医生。它更适合做四件事：

1. 帮你把营养健康问题问得更清楚。
2. 帮你整理饮食记录、体检信息、看病前的问题清单。
3. 用比较稳妥、循证、实在的方式，给普通公众做营养健康科普。
4. 在用户明确同意且工具支持本地文件读写时，维护本地 Markdown 健康档案，避免长期咨询时上下文断层。

项目地址：

https://github.com/guzhong1/ask-guzhongyi

## 这是什么

这是一个面向 AI 工具的 Skill，也可以理解成一套“顾中一式营养咨询工作流”。

它会尽量做到：

1. 先给你一个直接、简明的科普回答。
2. 需要深入时，再少量追问关键信息。
3. 先抓主要矛盾，不被细枝末节带跑。
4. 不把健康建议讲得过度精确、过度吓人、过度商业化。
5. 遇到疾病、用药、急症和高风险情况时，明确提醒你回到线下医生。

## 适合问什么

1. “我想减肥，晚饭该怎么吃？”
2. “我今天这顿饭吃得怎么样？”
3. “体检血脂高，饮食上一般要注意什么？”
4. “维生素 D、钙片、复合维生素到底有没有必要？”
5. “我准备去看医生，能帮我整理一页病情摘要吗？”
6. “医生开了处方，能帮我整理一下我需要注意和复诊时要问的问题吗？”
7. “请帮我把身高、体重、疾病、饮食和运动记录到本地健康档案里。”

## 不适合问什么

1. 不适合让它给你诊断。
2. 不适合让它替代医生。
3. 不适合让它决定停药、换药、加药或改剂量。
4. 不适合急症、重症、持续加重症状、儿童、孕产妇、复杂慢病等高风险场景。
5. 不适合让它推荐具体品牌、产品、平台、课程。

如果你有胸痛、呼吸困难、意识异常、突发肢体无力或言语不清、严重过敏、呕血黑便、严重脱水、剧烈腹痛、自伤风险等情况，请直接线下就医或急诊评估。

## 怎么安装

### 方式一：会用命令行

```bash
git clone https://github.com/guzhong1/ask-guzhongyi.git
cp -R ask-guzhongyi/skill/ask-guzhongyi ~/.codex/skills/
```

然后在支持 Skills 的 AI 工具中调用 `ask-guzhongyi`。

### 方式二：不会命令行

1. 打开项目地址：https://github.com/guzhong1/ask-guzhongyi
2. 点击绿色 `Code` 按钮。
3. 点击 `Download ZIP`。
4. 解压后，找到 `skill/ask-guzhongyi` 文件夹。
5. 把这个文件夹放到你的 AI 工具指定的 Skills 目录中。

如果你的工具不支持 Skill，也可以打开 `skill/ask-guzhongyi/SKILL.md`，把其中的规则复制到支持自定义提示词或智能体的平台里使用。

## 本地健康档案

这个 Skill 的长期咨询体验，建议配合本地 Markdown 健康档案使用。这样以后再问时，智能体可以参考你之前记录过的基本情况、饮食、运动、疾病和家人信息，减少上下文断层。

首次使用时，智能体应该先征得你同意，再创建本地档案。创建或更新后，它会提示：

```text
我已经把这次信息记录到本地 health-records/ 文件夹下了。以后你再咨询时，我可以参考这些本地 Markdown 档案。它们保存在你的本地电脑上，本 Skill 不会上传到云端。
```

使用本地健康档案有两个前提：

1. 你使用的 AI 工具必须支持本地文件读写。
2. 你必须明确同意记录，智能体不应该偷偷保存健康信息。

推荐的私人档案目录是：

```text
health-records/
  self.md
  people/
    father.md
    mother.md
  daily/
    2026-05.md
```

`health-records/` 已经写入 `.gitignore`，真实健康档案不要上传到 GitHub。

本地档案适合记录：

1. 身体状况：身高、体重、已明确诊断、过敏史、用药、重要检查指标。
2. 日常数据：饮食总热量估计、饮食结构、运动量、睡眠、症状变化。
3. 关联人员：家人或其他咨询对象的称呼、关系、基本情况、身体状况、就医沟通信息。

## 怎么提问

你可以这样问：

```text
我想减肥，身高 170cm，体重 78kg，平时久坐，晚饭经常点外卖。你能帮我看看一般怎么调整吗？
```

```text
这是我今天的一餐：米饭一碗、红烧肉几块、炒青菜一份、奶茶一杯。你能帮我从营养结构上看看吗？
```

```text
我已经被医生诊断为高脂血症，目前没有吃药。饮食上一般要注意什么？哪些情况需要回去问医生？
```

```text
我下周要去看医生，主要问题是最近一个月反复胃痛。你能帮我整理一页给医生看的病情摘要和问题清单吗？
```

```text
医生给我开了药，我不想让你改药，只想帮我整理一下每个药大概是做什么的，以及我下次复诊该问什么。
```
